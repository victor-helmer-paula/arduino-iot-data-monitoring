# Lab 03 – Data Acquisition, Processing and Visualization with Python

## 📖 Description
This project extends the Arduino sensor monitoring system by collecting sensor data through serial communication and processing it using Python in a Jupyter Notebook.

It was developed as part of the Applied Physics for Computing course at IPBeja.

---

## 🎯 Objectives
- Read sensor data sent by the Arduino through the serial port
- Allow the user to define the number of readings to collect
- Associate each reading with a timestamp
- Process and visualize sensor data using Python
- Generate descriptive statistics
- Detect alerts based on user-defined thresholds
- Export collected and processed data to Excel

---

## 🧠 Data Processing Features
- Serial data acquisition
- Data cleaning and organization
- Graph generation
- Descriptive statistics:
  - Minimum
  - Mean
  - Median
  - Maximum
  - Standard deviation
- Alert detection with timestamp association
- Export to `.xlsx` with metadata

---

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- OpenPyXL
- PySerial
- Arduino Nano RP2040 Connect

---

## 📁 Files
- `T3.ipynb` → Jupyter Notebook with analysis, visualizations and report
- `dados_fisica_lab3.xlsx` → exported dataset and processed results
